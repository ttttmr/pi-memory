# pi-memory

[English](README.md) | 简体中文

Pi 的跨会话 Markdown 记忆扩展。让 Agent 记住有用的知识，在后续会话中查找和复用。

## 功能

- 跨会话复用：保存项目约定和工作经验，换一个会话后仍可查找，不必重新交代。
- 项目与全局记忆：项目细节相互隔离，非私密的通用偏好和经验可以跨项目共享。
- 自主读写笔记：Agent 可搜索、读取、更新和归档本地 Markdown，不用手写工具参数。
- 后台整理：回看同项目历史，发现遗漏经验，纠正或合并已有笔记，并维护索引。

## 安装

需要 Pi、Git 和 Node.js 22.19 或更新版本。

```bash
pi install git:github.com/ttttmr/pi-memory
```

安装后，在你要工作的项目目录中运行 `pi`。默认后台整理会额外调用模型，可用 `pi --pi-memory-no-dream` 关闭。

## 使用

在 Pi 会话内输入：

```text
/memory 这个项目用 npm run check 做完整检查，交付前先跑一次。
```

之后在同一项目的新会话中正常提问：

> 这个项目交付前应该跑什么检查？请查一下之前的记忆。

Agent 自主决定保存什么、怎样组织笔记，不保证每段对话都会保存。需要保留时，可以让它读取已保存的笔记确认。
